Returning to First Principles

Modern frontend engineering has created an enormous tower of fragile abstractions. Developers now routinely download hundreds of megabytes of nested packages, configure complex bundlers, and wait through lengthy CI pipelines just to compile basic HTML pages.

Kaze (風, meaning Wind in Japanese) was built as an antidote to this complexity. It proves that Python's standard library is already a complete, world-class toolchain for static web generation.

By relying entirely on built-in standard library modules, Kaze delivers 0.01-second builds, zero maintenance overhead, and total immunity to upstream supply-chain risks. It runs on any machine with Python 3, today and ten years from now.
