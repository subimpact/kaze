About Kaze

Kaze (風) means wind in Japanese. The goal is a build step light enough to read in one sitting.

Where it came from

Kaze started as a starter kit for agency client sites. Most of those sites needed the same pages: a homepage, an about page, a contact page, articles, and case studies. Instead of setting up a framework each time, the build became one Python file that fills HTML templates from JSON content.

It uses only the Python standard library, so any machine with Python 3.8 or newer can build it without installing anything.

What it is not

Kaze is not a replacement for Hugo, Pelican, Eleventy, or Astro. It has fixed page types, basic Markdown, and no plugins. If your site needs more than that, those tools are the better choice. The comparison article goes into more detail.
