What Kaze is

A starter for agency and small-business sites, with the build step kept small enough to read in one sitting.

{{services_items}}

Try it in three commands

If you have Python 3.8 or newer, there is nothing else to install.

bash 
# 1. Get the code
git clone https://github.com/subimpact/kaze.git my-site
# 2. Preview locally at http://localhost:8000 (rebuilds on change)
cd my-site && python3 dev.py
# 3. Build the static site into dist/
python3 build.py

Kaze is not for every site

The page types are fixed and the Markdown support is basic. If you need more, these are better choices.

Kaze

Pick it when your site fits the built-in pages (home, about, contact, articles, case studies) and you want to read and change every line of the build.

Hugo

Pick it for a mature, very fast generator with many themes. It ships as a single binary.

Pelican

Pick it for a full-featured Python generator with Jinja2 templates and plugins.

Eleventy

Pick it if you work in Node.js and want flexible templating with a simple model.

Astro

Pick it when you need components, client-side interactivity, or its integrations.

How it works

One script, four steps, no hidden configuration.

原

Content

Site settings, team, articles, and case studies are JSON files in content/. Article bodies are Markdown.

枠

Templates

Plain HTML files with {{placeholders}} and simple show/hide blocks. No template language to learn.

紡

Build

build.py fills the templates, converts Markdown, and writes the pages, sitemap, and JSON-LD to a clean dist/.

端

Deploy

Upload dist/ to any static host. Cloudflare Pages can also build it from Git with python3 build.py.
